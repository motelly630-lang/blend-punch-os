2026-09-11 EC2 트리 정리 후 남은 추적외 파일. **로컬에도 git 에도 없다.**
`git reset --hard` 는 추적외 파일을 지우지 않으므로 유실은 없었다.

```
app/api/remove_bg.py
app/models/auth.py
app/models/image_service.py
app/models/orders.py
app/routers/image_service.py
app/routers/agent_pipeline.py.bak
app/templates/outreach/detail.html
app/templates/outreach/list.html
app/templates/trends/trends.py
```

**전부 미참조임을 확인했다** (2026-09-11):
- `image_service` / `remove_bg` 참조는 모두 `app/services/image_service.py`(git 에 있음)를 가리킨다.
  `app/models/image_service.py` · `app/routers/image_service.py` · `app/api/remove_bg.py` 는 어디서도
  import 되지 않는다.
- `app/routers/outreach.py` 가 렌더하는 템플릿은 `outreach/index.html` 과 `outreach/form.html` 뿐이고
  둘 다 git 에 있다. `list.html` · `detail.html` 은 쓰이지 않는다.
- `app/main.py`(git 판본 = 현재 EC2 판본)가 이 모듈들을 등록하지 않는다.

**따라서 잠재적 배포 장애는 없다.** 구조 변경 이전의 잔재다.

**정리 방법 (급하지 않음):** 삭제 전에 `.deploy-backup/` 으로 옮기거나 백업 tar 에 담아두고,
운영 재시작 후 정상 동작을 확인한 뒤 지운다. `agent_pipeline.py.bak` 은 그냥 지워도 된다.
