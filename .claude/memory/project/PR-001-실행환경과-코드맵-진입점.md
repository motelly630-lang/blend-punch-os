기술스택: FastAPI + PostgreSQL(RDS) + Jinja2 + Tailwind(정적빌드) + htmx + Alpine.js.
운영 `os.blendpunch.com` (EC2 + Cloudflare).

**이 문서는 지식을 복사해 담지 않는다 — 어디를 읽을지만 가리킨다.** 내용을 여기 옮겨 쓰면
원본과 갈라져 거짓 정보가 된다.

| 알아야 할 것 | 읽을 곳 |
|---|---|
| 실행환경·라우터 URL 표·반드시 지킬 규칙 8개 | `CLAUDE.md` (113줄, 지도) |
| 업무 흐름·모델 필드·계산 로직·기술부채·미결 질문 | `BLENDPUNCH_OS_SECOND_BRAIN.md` (572줄) — **필요할 때만** |
| 기능명만 알 때 파일 찾는 절차 | `/os-locate` 스킬 (grep-first, 전체 읽기 금지) |
| 사람 대상 업무 안내 | `블렌드펀치_직원_온보딩_가이드.md` (192줄) |

규모: 라우터 40개(`include_router` 39회), 모델 37개, 서비스 16개, 템플릿 119개, AI 엔드포인트 10종.
기능 하나 = `app/routers/<name>.py` + `app/models/<name>.py` + `app/templates/<name>/` 3점 세트.

앱 상태는 **DB가 출처**다 — 기능 플래그는 `CompanyFeature`, 사업자정보는 `BusinessInfo`(싱글톤 행).
`.env`에는 진짜 시크릿만 있다. 메모리에 이 값들을 복제하지 말고 조회 경로만 가리킨다.
