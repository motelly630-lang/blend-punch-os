대표님 지시 (2026-09-24, 명시): 대화·작업에서 배운 것을 쌓아 갈수록 정확하고 빠르게 일하게 하되,
**대화를 전부 저장하지 않는다.**

- 반복 가능한 절차·검증 → 스킬 / 선호·공통 원칙·필수 규칙 → CLAUDE.md 등 공통 지침 /
  사업·프로젝트 사실·결정·이유 → 지식 문서 / 역할이 분명한 독립 업무 → 에이전트 /
  일회성·미확인 추측 → 영구 규칙으로 만들지 않는다.
- 대표님이 **반복 설명**하거나, **결과를 수정**하거나, **실패 원인·해결이 확인**되면 개선 후보로 잡는다.
- 한 번의 상황을 모든 작업으로 넓히지 않는다 — **적용 조건**을 적는다.
  **대표님이 정한 원칙(명시)과 내가 추론한 개선안(추론)을 구분**한다.
- 기존 것과 겹치면 새로 만들지 말고 개선. 필요한 것만 찾아 쓰게 한다 (전부 읽지 않는다).
- 비밀번호·API 키·고객 개인정보는 옮기지 않는다.
- 작은 안전한 변경은 진행, 대규모 덮어쓰기·삭제·외부 전송·비용 설정은 먼저 확인.
