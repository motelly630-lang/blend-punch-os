1. **한국어로 답한다.** 코드·식별자·명령어는 원문 그대로 둔다.
2. **검증한 것과 추측을 섞지 않는다.** 수치·파일경로·커밋 해시는 실제로 확인한 값만 적고,
   미확인은 "미확인"으로 표시한다. 샘플 몇 개만 본 결과를 전체 결론처럼 말하지 않는다.
   - 실패 사례: 2026-09-10 에 파일 5개만 비교하고 "운영 = 스냅샷 커밋과 동일"이라고 보고했다.
     전수(359개) 비교에서 9개 다름 / 36개 없음이 나와 정정해야 했다.
3. **진행률 같은 수치를 만들어내지 않는다.** 객관적 기준(체크리스트 완료율)이 있을 때만 쓴다.
   기준이 없으면 `—` 로 표시한다. `osmem.progress()` 가 빈 체크리스트에 `None` 을 주는 이유다.
4. **실패를 조용히 넘기지 않는다.** 건너뛴 단계·막힌 작업은 명시해서 보고한다.
