판매 페이지 → OS, 한 번에 복사

스마트스토어·쿠팡·자사몰에서 제품 페이지를 연 채로 이 버튼을 누르면 대표 사진·가격·제품명·링크가 복사됩니다. OS 빠르게 채우기에서 📋 붙여넣기를 누르면 제안으로 뜨고, 적용을 눌러야 저장돼요.

이 버튼을 즐겨찾기 막대로 끌어다 놓으세요
📋 OS로 복사
  1. 즐겨찾기 막대가 안 보이면 ⌘ + Shift + B (윈도우는 Ctrl + Shift + B)를 누르세요.
  2. 위의 📋 OS로 복사 버튼을 마우스로 잡아 즐겨찾기 막대에 놓으세요.
  3. 네이버에서 제품을 찾아 상품 페이지를 연 상태에서 즐겨찾기 막대의 📋 OS로 복사를 누르세요.
  4. OS 빠르게 채우기에서 해당 제품 줄의 📋 붙여넣기를 누르세요.
끌어다 놓기가 안 될 때 (직접 추가)
  1. 즐겨찾기 막대에서 오른쪽 클릭 → 페이지 추가(또는 북마크 추가)
  2. 이름: OS로 복사
  3. URL 칸에 아래 글자를 전부 복사해 붙여넣고 저장

이 버튼은 대표님이 직접 보고 있는 페이지의 정보만 읽어 복사합니다. 사이트에 따라 가격을 못 찾으면 비워 두고, 사진·이름만 채워질 수 있어요.
